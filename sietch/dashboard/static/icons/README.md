# Dashboard Icons Attribution

The service icons in this directory are sourced from the
[selfhst/icons](https://github.com/selfhst/icons) project, maintained by
[selfh.st](https://selfh.st), and licensed under the Creative Commons
Attribution 4.0 International License (CC BY 4.0).

These icons are used by the OnRamp Dashboard to visually identify the various
self-hosted services. All product names, logos, and brands are property of their
respective owners.

The icons are downloaded as SVG files and served locally by the OnRamp Dashboard
so that the UI works without requiring internet access at runtime.

To refresh or update icons, run:

```bash
make download-icons
```

For more information, see `docs/dashboard.md`.
